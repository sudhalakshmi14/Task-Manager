# 📋 Task Management Application

A full-stack, responsive web application designed for creating, updating, and tracking daily tasks. This project showcases user authentication, database persistence, secure RESTful APIs, and dynamic frontend state synchronization.

## 🚀 Features

* **User Authentication & Authorization:** Secure user registration and login using passwords hashed with `bcryptjs` and session persistence via JSON Web Tokens (JWT).
* **Full CRUD Functionality:** Authenticated users can Create, Read, Update (toggle completion), and Delete tasks.
* **Data Isolation:** Users can only view, modify, or interact with their own specific tasks.
* **Responsive Layout:** A clean dashboard user interface built with Tailwind CSS that dynamically scales down seamlessly from desktop monitors to mobile displays.

## 🛠️ Tech Stack

**Frontend:** React (Vite), Tailwind CSS  
**Backend:** Node.js, Express.js, JWT, Bcrypt.js  
**Database:** MongoDB (via Mongoose ODM)
